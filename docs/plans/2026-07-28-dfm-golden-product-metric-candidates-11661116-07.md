## 1. 使用原则

这份报告提供了工程问题、项目参考值、候选阈值和问题区域，但不能直接当作生产规则库。

- “本产品测得值”进入黄金产品人工验收基线，不自动变成通用规则阈值；
- “判据及结果输出要求”是候选规则，需确认适用材料、铸造方式、区域和例外；
- 图片中的箭头、颜色面和圈选区域是 Ground Truth 标注来源，需由工程师转换为稳定的空间
  区域描述，不能依赖截图颜色或跨 Backend Face ID；
- `.x_t` 产品 B-Rep、模具/浇排模型和模流仿真结果是三类不同输入，不能要求 NX 产品几何
  Backend 从单个产品 `.x_t` 推导仿真结果；
- 报告与黄金产品实际输入必须通过文件版本、图纸版本和 SHA-256 对齐后，才能用于验收。

### 2.1 推荐的首条 NX 闭环范围

为了尽快打通真实业务链，第一轮建议冻结以下 P0 项：

```text
壁厚分布
+ 定模/动模/四个滑块方向的拔模分析
+ 六方向倒扣检测
→ Measurement
→ Hermes Evaluation
→ Finding + 问题区域 + Evidence
→ 工程师人工逐项核对
```

其中六个出模方向和分型区域不能由 Agent 猜测，应作为工程师确认事实或受控模具方案输入。

### 3.1 锁模力公式异常

报告第 27 页写为：

```text
1.2 × {80 × (1200 + 650) / 100 + 193} = 1961 KN
```

按页面所列数字直接计算，括号结果与 `1961` 不一致；`2000T` 与 `1961 KN` 也存在明显
单位量级疑问。因此当前只能把各输入值登记为候选事实，不能把该表达式、`1961 KN` 或
`2000T` 直接固化为规则或黄金结果。需要工程师确认：

1. `80` 的真实单位和换算系数；
2. `193 kN` 是否应加到主锁模力中；
3. 结果单位是 `kN`、`tf` 还是压铸机名义吨位；
4. 选型是向上选择 `2000T`，还是另有设备安全余量规则。

## 7. 工程师冻结前必须澄清的问题

1. 当前黄金 `.x_t` 与报告使用的产品版本是否完全一致？报告第 40–45 页多次提到“产品
   壁厚已经减肉”“新产品壁厚已更改”和“后续根据最新模流”，仿真结果可能对应旧版本。
2. 材料/合金是什么？`580°C` 是否是该材料批准的液相线或项目工艺下限？
3. 六个出模方向的精确向量、原点/坐标系和各自负责的区域是什么？
4. `1.5°` 是本产品所有普通成型面的统一下限，还是仅针对报告圈选区域？
5. 鹰嘴式进料搭子的 `0.5°–1°` 是允许区间还是最低要求？
6. “壁厚基本均匀”如何量化：允许范围、分位数、超限面积比例和需排除区域分别是什么？
7. 锁模力公式、换算单位、`1961 KN` 结果和 `2000T` 设备选择如何对应？
8. 报告中的 `1200/650/1085 cm²` 分别由哪些几何体、哪些投影方向计算？
9. 报告建议编号从 12 跳到 14，是否缺失第 13 项？
10. 哪些孔、平面和搭子属于后机加工区？是否能提供稳定的区域标注或成品/毛坯双模型？
